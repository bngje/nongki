# 🏢 Nongki - Workspace Booking Platform

[![Live Preview](https://img.shields.io/badge/Live%20Preview-Click%20Here-success?style=for-the-badge&logo=vercel&logoColor=white)](https://bngje.github.io/nongki/)
[![React.js](https://img.shields.io/badge/React-20232A?style=for-the-badge&logo=react&logoColor=61DAFB)](https://reactjs.org/)

**Nongki** adalah platform berbasis web modern untuk memudahkan pengguna dalam memesan ruang kerja (*workspace*) yang nyaman dan produktif. Proyek ini dibangun menggunakan **React.js** dengan fokus pada antarmuka yang menarik dan pengalaman pengguna (UX) yang mulus.

## ✨ Fitur Utama

* **Responsive Landing Page:** Desain antarmuka yang menarik dan adaptif untuk berbagai perangkat.
* **Booking Flow:** Alur pemesanan ruang kerja yang interaktif dan mudah dipahami.
* **User Authentication:** Simulasi login sederhana untuk mengakses fitur pemesanan.
* **Workspace Catalog:** Menampilkan berbagai pilihan ruang kerja dengan detail fasilitas.

---

## 🛠️ Teknologi yang Digunakan

* **Frontend:** [React.js](https://reactjs.org/)
* **Styling:** CSS
* **State Management:** React Hooks (useState, useEffect)

## 🚀 Cara Menjalankan Project (Localhost)

Ikuti langkah-langkah ini untuk menjalankan proyek di komputer kamu:

1.  **Clone repositori ini:**
    ```bash
    git clone [https://github.com/bngje/nongki.git](https://github.com/bngje/nongki.git)
    ```

2.  **Masuk ke direktori project:**
    ```bash
    cd nongki
    ```

3.  **Install dependencies:**
    ```bash
    npm install
    # atau
    yarn install
    ```

4.  **Jalankan server development:**
    ```bash
    npm start
    # atau
    yarn start
    ```

5.  Buka browser dan kunjungi `http://localhost:3000`.
